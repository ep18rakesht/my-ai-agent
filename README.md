# My AI Agent

A conversational AI chatbot that runs completely on your local laptop — no internet required, no API keys, 100% free and private.

## What it does
- Answers any question you ask
- Remembers the full conversation (has memory)
- Runs on your own laptop using Llama 3.2

## Tech stack
- Python
- Ollama (local AI runner)
- Llama 3.2 (free, open-source AI model by Meta)

## How to run it

### 1. Install Ollama
Download from https://ollama.com and install it.

### 2. Download the AI model
```bash
ollama pull llama3.2
```

### 3. Install dependencies
```bash
pip install ollama
```

### 4. Run the agent
```bash
python agent.py
```

## How to use it
- Type any question and press Enter
- The agent will reply
- Type `quit` to exit
